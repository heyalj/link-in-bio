# My Links - Project Brief 
A personal link-in-bio page. One page, clean design, mobile-friendly. 
I want to send peopel here from my social profiles. 

## Tech 
- Pure HTML, CSS and javaScript - no frameworks, no build tools
- Single index.html file (CSS and JS can be separate files)
- Deploys to Vercel as a static site

## Design 
- Centerd card layout, max-wdith 480px
- My name as a heading, short bio underneath 
- Here is my bio: "Of Houston origin, matured in New York, and aged across Fortune 50 boardrooms with strong forward notes of enterprise UX, AI-driven product transformation, and design operations at scale. Finish includes a founder's instinct, a 2X TEDx stage, and a LEED-certified architecture license. Pairs well with custom sneakers, running, and hip-hop."
- Profile photo placeholder (circle, 120px)
- Dark mode by default with a light/dark toggle
- Smooth hover animations on the link buttons
- Font: Avenir Next
